# memory-os

Monitor de memória RAM em Node.js que exibe memória livre, total e porcentagem a cada segundo.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Monitor em `stats.js`.

**Tecnologias:** `JavaScript`, `Node.js`.

## Executar localmente

```bash
node stats.js
```
